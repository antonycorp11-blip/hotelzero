# HOTEL ZERO

Vertical slice jogável de uma aventura narrativa 2D top-down sobre investigação, possessão e loops temporais.

```bash
npm install
npm run dev
```

Controles: WASD/setas para mover, E para interagir, J para o diário, M para o mapa mental e Shift para acelerar o relógio. Em telas de toque horizontais, use o joystick e os botões sobrepostos.

Consulte [`docs/PHASE-1.md`](docs/PHASE-1.md) para o recorte implementado e [`docs/ASSET-BRIEFS.md`](docs/ASSET-BRIEFS.md) para o pipeline de arte.
